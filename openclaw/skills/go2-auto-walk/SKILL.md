# Go2 Auto Walk - 自主遛狗模式

让机器狗像自动驾驶汽车一样自主行走！自动发现前方可走路径，智能避障，自动转弯，动态调速。

## 功能特点

- 🔍 **路径发现**：自动分析前方路况，识别可行走区域
- 🚧 **智能避障**：检测障碍物并自动绕行
- ↪️ **自动转弯**：遇到路口自动决策转弯方向
- ⚡ **动态调速**：根据路况复杂度自动调整行走速度
- 🛡️ **安全保护**：检测危险区域（楼梯、悬崖）自动停止

## 工作原理

```
拍照 → VLM分析路况 → 决策引擎 → 运动控制 → 循环
```

**路况分析：**
- 识别可行走地面（地板、平地）
- 检测障碍物（家具、墙壁、人）
- 发现危险区域（楼梯、门槛、悬崖）
- 判断空间开阔程度

**决策逻辑：**
- 前方通畅 → 直行，适当加速
- 前方有障碍 → 减速，规划绕行路径
- 遇到路口 → 选择更开阔的方向转弯
- 危险区域 → 立即停止，后退

**速度控制：**
- 开阔无障碍 → 快速 (0.5 m/s)
- 一般路况 → 中速 (0.3 m/s)
- 复杂/狭窄 → 慢速 (0.15 m/s)
- 接近障碍 → 极慢 (0.08 m/s)

## 使用方法

### 基础用法

```bash

# 行走60秒后自动停止
```

## 参数配置

在 `auto_walk.py` 中可以调整：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `SAFE_DISTANCE` | 1.0 | 安全距离（米），发现障碍物时开始减速 |
| `MIN_CLEARANCE` | 0.5 | 最小通行宽度（米），小于此宽度需要绕行 |
| `MAX_SPEED` | 0.5 | 最大行走速度 (m/s) |
| `MIN_SPEED` | 0.08 | 最小行走速度 (m/s) |
| `DECISION_INTERVAL` | 2.0 | 决策间隔（秒），多久分析一次路况 |
| `SCAN_ANGLE` | 30 | 扫描转弯角度（度），用于探索侧方路径 |

## 技术实现

### VLM 路况分析
使用视觉语言模型分析前方路况：
- **可行走区域**：识别地板、地毯、平地
- **障碍物**：家具、墙壁、人、宠物
- **危险区域**：楼梯、门槛、台阶、悬崖
- **空间分析**：开阔程度、通道宽度

### 决策引擎

**路况评估（5级）：**
1. **畅通** (5) - 开阔无障碍，可全速前进
2. **良好** (4) - 有充足空间，可中速前进
3. **一般** (3) - 需要小心，减速前进
4. **拥挤** (2) - 空间狭窄，极慢速或绕行
5. **危险** (1) - 有危险，停止或后退

**行动决策：**
```python
if 路况 == "畅通":
    动作 = "直行", 速度 = MAX_SPEED
elif 路况 == "良好":
    动作 = "直行", 速度 = 中速
elif 路况 == "一般":
    动作 = "直行", 速度 = 慢速
elif 路况 == "拥挤":
    动作 = "扫描侧方", 选择更开阔方向转弯
elif 路况 == "危险":
    动作 = "停止", 必要时后退
```

### 侧方扫描机制
当正前方路况不佳时，机器狗会：
1. 左转30度拍照分析左侧路况
2. 右转60度拍照分析右侧路况
3. 比较三个方向的路况评分
4. 选择评分最高的方向前进

## 安全机制

⚠️ **多重安全保护：**

1. **危险区域检测**：识别楼梯、悬崖等立即停止
2. **紧急停止**：人工按 Ctrl+C 立即停止所有动作
3. **速度限制**：即使畅通也不会超过安全速度
4. **定期检查**：每2秒重新评估路况
5. **超时保护**：可设置最大行走时间

## 故障排除

| 问题 | 解决 |
|------|------|
| 不走路 | 检查是否站立状态，先执行 stand_up |
| 撞东西 | 减小 MAX_SPEED，增加 SAFE_DISTANCE |
| 转弯太频繁 | 增大 DECISION_INTERVAL |
| 识别不准确 | 确保光线充足，地面特征明显 |
| 原地打转 | 检查 VLM 分析结果，可能需要调整提示词 |
